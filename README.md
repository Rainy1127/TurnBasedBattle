# Turn Based Battle

This is a personal C++ project that represents a battle system of a turn-based RPG. 

## Goals

- Turn order based on initiative.
- Action Points.
- Abilities loaded from JSON, not written in code.
- Minimum 2 status effects (planned: burning and stun).
- Basic enemy AI: decisions based on rules, not random.
- Unit tests.
- Memory checks with a sanitizer or Valgrind, no leaks.

## Status

The repository and CMake template are ready. The program builds and prints a line to the console.
The battle system is planned for January–February 2027, in the meantime, I'm preparing for it while learning C++.
